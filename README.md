# M2 UTM Builder

Работает локально: откройте `index.html` в браузере. Сервер, БД и интернет не нужны.

## Настройка (всё в `config.js`)
- `allowedUsers` — список разрешённых e-mail (`[]` отключает проверку).
- `dictionaries` — допустимые значения для выпадающих списков.
- `strictDictionary` — поля, значение которых обязано быть в словаре (utm_source, utm_medium).
- `required`, `freeText`, `campaignParts`, `prefixes` — состав и порядок полей, префиксы в utm_campaign.

Правьте файл руками и обновите страницу. Исходный `data.csv` оставлен как справочник, приложением не используется.
