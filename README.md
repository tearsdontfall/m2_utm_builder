# M2 UTM Builder

Конструктор UTM-ссылок по стандартам M2. Статический сайт на HTML, CSS и JS, без сборки и сервера.

## Структура проекта

```
├── index.html   — разметка страницы
├── script.js    — логика: потоки, автозаполнение, валидация, сборка ссылки
├── config.js    — все данные и настройки (правится руками)
├── style.css    — стили
└── README.md
```

| Файл | За что отвечает |
|---|---|
| `index.html` | Каркас формы: вход по e-mail, базовый URL, блок «Направление трафика», блок `utm_campaign`, блок доп. UTM-меток, результат. Сами поля рисует `script.js`. |
| `script.js` | Отрисовка полей по `config.js`, переключение потоков, предзаполнение фиксированных сущностей, проверка обязательных полей, сборка `utm_campaign` и итоговой ссылки, копирование. Данных не содержит. |
| `config.js` | Источник всех данных: потоки разметки (направления, площадки, `utm_source`, `utm_medium`, фиксированные сущности), словари сущностей, названия полей, обязательные поля, порядок и префиксы, список разрешённых e-mail. |
| `style.css` | Оформление формы, раскрывающихся блоков и меток «авто». |
